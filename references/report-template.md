# Full Assessment Template

Use this structure for a full "where/how should I (we) move" assessment. Collapse sections for narrower questions.

## 1. Bottom line
Two to four sentences giving the strongest route, the best backup, and the single most important next action.

## 2. Client profile
A concise table or short paragraph per applicant: age (and the next age-points drop), nationality, current status, education, assessed experience, language (tested vs assumed), family, finances if known, and goals. List any assumptions made.

## 3. Route ranking
| Rank | Country & route | Grants (work/TR/PR) | Eligibility now | Est. likelihood | Time to PR | Time to citizenship | Spouse work rights | Cost range | Key risk |

## 4. Points estimates (where relevant)
Per-applicant breakdown by factor, labelled as estimates, with the levers that would move each score most.

## 5. Trade-offs and hidden risks
Short prose per top route.

## 6. Routes ruled out
One line each, with the hard requirement failed.

## 7. Action plan
- Next 30 days / 60 days / 90 days
- Long-lead items to start immediately (language tests, credential assessments, police certificates)
- Document checklist (see intake-checklist.md)
- Backup plan if the primary route stalls

## 8. Verification note
What was verified (with dates), what is volatile or contested, and the professional to consult before filing.
